Description:
Tahc Re Lab is a full-stack single-page web application that simulates a GPU manufacturing, purchasing, and resale platform. The application emphasizes interactivity, allowing users to book, update, or cancel reservations for specific components, as well as modify available parts. User information and account data can be updated seamlessly, with additional interactive features enhancing the overall experience.

The frontend is implemented with React, delivering a responsive and dynamic user interface. The backend leverages Node.js and Express to handle business logic and server-side operations. Google Firebase provides secure authentication and credential management, while all API communications are protected with JSON Web Tokens (JWT) to ensure data integrity and user privacy.

A role-based dashboard system supports two tiers of access:

Administrator: empowered to oversee, update, and manage stored data.

Standard User: enabled to book, purchase, submit reviews, and interact with platform features.

This project demonstrates the integration of modern web technologies to deliver a secure, scalable, and interactive single-page application.
